# ユビキタス言語

コード・画面・資料で同じ言葉を使う。数値の正は `packages/shared/src`。

## 地域

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 市区町村 | 分析の単位。政令市の区も 1 つとして扱う（例: 横浜市緑区） | `Municipality` / `area` |
| 市区町村コード | 全国地方公共団体コードから検査数字を除いた **5 桁** | `MunicipalityCode`（`^\d{5}$`） |
| 都道府県コード | `01`〜`47` の 2 桁 | `PrefectureCode` |
| 代表点 | 地図で市区町村を指す点。境界の最大の面の重心 | `center` |
| 地区 | 大字・町名。取引の所在の細かさの上限 | `district` |

## 期間

| 用語 | 意味 |
|---|---|
| 四半期 | `2025Q2` の形。画面では「2025年4〜6月」 |
| 直近 4 四半期 | 公表が追いつかない当四半期を除いた、直前から 4 つ |
| 時点 | 指標の元データの時期。期間（from〜to）か時点（asOf）のどちらか |
| 出典 | 指標の元データの種類（`DataSourceKey`） |

## 指標（市区町村ごと）

| 用語 | 定義 | 単位 | 良い向き | キー |
|---|---|---|---|---|
| 取引価格 | 直近 4 四半期の中古戸建（宅地(土地と建物)）の取引価格の中央値 | 万円 | 低 | `tradePrice` |
| 想定表面利回り | 家賃相場 × 12 ÷ 取引価格 | % | 高 | `grossYield` |
| 家賃相場 | 民営借家の 1㎡家賃 × 中古戸建の延床面積の中央値（1000 円単位） | 円/月 | — | `monthlyRent` |
| 空き家率 | 空き家数 ÷ 住宅総数（住宅・土地統計調査） | % | 低 | `vacancyRate` |
| 放置空き家率 | 「その他の空き家」÷ 住宅総数 | % | 低 | `otherVacancyRate` |
| 空き家率の増減 | 前回調査（5 年前）との差 | pt | 低 | `vacancyRateChange` |
| 人口 | 住民基本台帳人口（最新年） | 人 | 高 | `population` |
| 人口増減率 | 5 年前比 | % | 高 | `populationChangeRate` |
| 将来人口の増減率 | 社人研推計の 2050 年 ÷ 2020 年 | % | 高 | `projectedChangeRate` |
| 土地の取引単価 | 直近 8 四半期の宅地(土地)の㎡単価の中央値。画面では坪単価 | 円/㎡ | 低 | `landUnitPrice` |
| 取引 ÷ 公示地価 | 土地の取引単価 ÷ 住宅地の地価の中央値。1 未満は公的評価より安い | 倍 | 低 | `landToOfficialRatio` |

## 信頼性と判定

| 用語 | 意味 | 値 |
|---|---|---|
| 参考値 | 取引件数が少なく、ぶれやすい値。ランキングでは既定で除く | 件数 < `RELIABLE_TRADE_COUNT`（10） |
| データなし | 元データが無い、または計算できない（null） | — |
| 市場の歪み | 同じ都道府県内での「需要の順位 − 価格の順位」。正が大きいほど需要の割に安い | -100〜100pt |
| 歪みあり | 市場の歪みが閾値以上 | ≥ `DISTORTION_THRESHOLD`（40） |
| 需要の弱さ | 利回り上位 2 割 かつ 人口減 かつ 空き家率上位 2 割。歪みのランキングから除く | `weakDemand` |
| 一言の判定 | 価格・人口・空き家を都道府県内の位置などで短文にしたもの | `verdict` |

市場の歪みの 3 種類:

| キー | 需要 | 価格 |
|---|---|---|
| `rentGap` | 人口増減率 | 1㎡家賃 |
| `landGap` | 人口増減率 | 土地の取引単価 |
| `momentumGap` | 地価の前年比 | 土地の取引単価の前年比 |

## 地価

| 用語 | 意味 |
|---|---|
| 公示地価 | 地価公示。1 月 1 日時点（`official`） |
| 基準地価 | 都道府県地価調査。7 月 1 日時点（`prefecture`） |
| 妥当な範囲 / よくある範囲 | 分布の 25%〜75% 点 |
| 距離帯 | 駅から徒歩 10 分以内 / 20 分以内 / それ超（徒歩 1 分 = 80m） |
| 地価補正 | 取引時期の違いを住宅地の地価の前年比で最新時点にそろえること |

## マンション

| 用語 | 意味 |
|---|---|
| 成約事例 | XPT001 の中古マンション等の取引 |
| 成約価格 | レインズ由来（`contract`） |
| 取引価格（マンション） | アンケート由来（`transaction`） |
| 事情のある取引 | 備考（remarks）が付いた取引。既定で除く |

## 利用者のデータ

| 用語 | 意味 | 上限 | ログイン |
|---|---|---|---|
| お気に入り | 市区町村コードの一覧 | 200（`MAX_FAVORITES`） | 必要 |
| 比較リスト | 並べて比べる市区町村 | 3（`MAX_COMPARE`） | 不要（ブラウザに保存、ログイン中はサーバーにも） |
| 保存した条件 | ランキングの絞り込み条件に名前を付けたもの | 20（`MAX_FILTERS`） | 必要 |

## システム

| 用語 | 意味 |
|---|---|
| 画面 | `apps/web`。ビルド時に全ページを HTML にする静的サイト |
| バッチ | `apps/batch`。公的 API を呼ぶ唯一の部品 |
| 保存 API | `apps/api`。利用者のデータを読み書きする |
| raw テーブル | 公的 API の応答を加工せずに入れた BigQuery の表（`raw_*`） |
| 集計テーブル | raw から SQL で作った表（`area_metrics` など） |
| 書き出し | 集計テーブルを GCS に JSON で出したもの（`exports/`）。`export_id` で世代を見分ける |
| サンプルデータ | 書き出しが無いときに画面が使う架空の値（`sample: true`） |
