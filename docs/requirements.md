# 要件定義

用語は [ユビキタス言語](ubiquitous-language.md) に従う。

## 1. 目的

中古戸建・土地を買おうとしている一般の人が、**公的データだけで**市区町村の相場と将来性をすばやく比べられるようにする。

- 物件探しの前に「どこを見るか」を決める材料を出す
- 気になったエリアは PropFolio（収支計算）へ値を引き継ぐ

## 2. 利用者

| 利用者 | したいこと |
|---|---|
| 閲覧者（未ログイン） | 指標を見る、ランキングで探す、地図で探す、3 つまで比べる |
| ログイン利用者 | 上に加えて、お気に入り・比較リスト・条件を保存し、別の端末でも使う |
| 運営者 | データを定期的に自動更新し、手作業なしで画面を作り直す |

## 3. 機能要件

| # | 機能 | 内容 | 画面 |
|---|---|---|---|
| F1 | 市区町村の検索 | 名前の部分一致で探す（⌘K） | 全ページ |
| F2 | 市区町村の詳細 | 主な指標、一言の判定、地価、空き家、市場の歪み、推移、人口、直近の取引 | `/areas/{code}/` |
| F3 | ランキング | 13 指標・都道府県で並べ替え。参考値とデータなしの扱いを選べる | `/rankings/` |
| F4 | 比較 | 3 つまで横に並べ、良い方を強調する | `/compare/` |
| F5 | 地図 | 指標で塗り分け、地価の地点と駅の相場を重ねる | `/map/` |
| F6 | マンション成約事例 | 都道府県ごとに駅単位で相場と事例を見る。条件で絞る | `/condos/` |
| F7 | 土地の価格チェック | 地区・面積・価格を入れると相場の中での位置を出す | 詳細 |
| F8 | ログイン | Google またはメールアドレス（PropFolio と共通） | 全ページ |
| F9 | 保存 | お気に入り・比較リスト・保存した条件 | 詳細・ランキング・比較 |
| F10 | PropFolio 連携 | 取引価格・家賃などを付けて PropFolio を開く | 詳細・比較 |
| F11 | データの自動更新 | 公的データを定期的に取り直し、画面を作り直す | — |
| F12 | アカウント削除への追従 | Clerk でアカウントを消したら保存データも消す | — |

## 4. データ要件

| データ | 取得元 | 更新頻度 |
|---|---|---|
| 不動産取引価格 | 不動産情報ライブラリ XIT001 | 毎月（直近分を取り直す） |
| 駅ごとの取引・マンション事例 | 不動産情報ライブラリ XPT001 | 毎月 |
| 地価公示・地価調査 | 不動産情報ライブラリ XPT002 | 年 2 回（4 月・10 月） |
| 駅・路線 | 不動産情報ライブラリ XKT015 | 年 1 回 |
| 空き家・家賃・人口 | e-Stat | 年 1 回 |
| 将来推計人口 | 社人研（IPSS） | 年 1 回（推計は約 5 年ごと） |
| 市区町村の境界 | 国土数値情報 N03 | 年 1 回（手動） |

すべての指標に**時点と出典**を表示する。件数が少ない値は**参考値**と明示する。

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| 性能 | 閲覧時にサーバーも DB も動かさない。全ページを CDN から配る |
| 可用性 | 更新が途中で失敗しても、前回の画面・データのまま動き続ける |
| 冪等性 | バッチは何度実行しても結果が同じ |
| セキュリティ | 本人のデータだけ読み書きできる。保存 API はロードバランサ経由のみ。レート制限 120 回/分/IP |
| プライバシー | 個人情報（ユーザー ID・メール・本文）をログに出さない。運営側に保存するのは Clerk のユーザー ID と保存データだけ |
| 秘匿情報 | API キー等は Secret Manager に置き、コード・ログに出さない |
| 軽さ | 閲覧だけの人には Clerk を読み込ませない。境界・マンションのデータは必要なページでだけ取る |
| SEO | 市区町村ごとに HTML・title・canonical・sitemap を出す |
| 保守 | 依存は最小限。フレームワーク・ルーターを使わない。版は固定 |
| 利用条件 | 不動産情報ライブラリ・e-Stat の規約にある定型文と出典を表示する |

## 6. 対象外

- 個別物件の特定・評価（取引は地区名まで）
- 投資判断の助言（歪みの表示に明記する）
- 新築の分譲価格
